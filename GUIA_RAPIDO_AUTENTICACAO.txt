🚀 COMO USAR - GUIA RÁPIDO
============================

📌 FLUXO CORRETO AGORA:

1. Você clica no botão "ENTRAR" em login.html
2. Sistema valida credenciais no Firestore
3. Salva dados no sessionStorage
4. Redireciona para painel.html ✅ (SEM loop!)
5. Painel valida sessionStorage
6. Carrega painel normalmente ✅

---

🔧 O QUE FOI CONSERTADO:

❌ ANTES:
firebase.auth().onAuthStateChanged(user=>{
  if(!user) location.href="index.html"; // 🔴 LOOP!
});

✅ AGORA:
window.addEventListener('DOMContentLoaded', () => {
  if (!sessionStorage.getItem('userUID')) {
    window.location.href = 'login.html';
  }
});

🚨 SE NÃO FUNCIONAR:

❓ Voltita para index.html depois de clicar "Entrar"?
→ Verifique se as credenciais estão corretas
→ Console deve mostrar qual erro específico

❓ Diz "sessionStorage não foi setado"?
→ Pode ser erro de conexão com Firebase
→ Verifique regras de segurança do Firestore

❓ Acesso negado ao painel?
→ Verifique se auth-check.js está sendo carregado (F12 > Network)
→ Verifique se sessionStorage tem dados (F12 > Application > Session Storage)
