Como funciona

  • O progresso é calculado automaticamente com a fórmula: (depositos + compras × 10) / metaVip × 100.
  • O valor é limitado a 100% para não ultrapassar o limite visual.
  • O nível VIP é definido com base na porcentagem atual:
  • VIP 1: 0–33%, VIP 2: 34–66%, VIP 3: 67–100%.
  • Os dados são atualizados com onSnapshot, portanto qualquer alteração no Firestore reflete imediatamente.
  • Se o documento do usuário não existir, o painel exibirá erro e não criará registros automaticamente.
